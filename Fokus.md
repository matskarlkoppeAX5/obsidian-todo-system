# Fokus

## Jetzt dran
Alles, was beim Sortieren mit #fokus markiert wurde.

```tasks
not done
tags include #fokus
sort by priority
hide backlink
short mode
```

## Fällig oder überfällig

```tasks
not done
(due before tomorrow) OR (scheduled before tomorrow)
group by filename
short mode
```
